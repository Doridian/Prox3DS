## Others

- `nfcprobe/source/zip.c`: inflate follows the structure of zlib's `puff.c` (Copyright (C) 2002-2013
  Mark Adler, zlib license).
- `nfcprobe/sim/metrics.h`: glyph advances measured from NanumGothic (NAVER Corporation, SIL Open Font
  License 1.1) by `nfcprobe/sim/gen_metrics.py`. The font itself is not included.
- `nfcprobe/source/jcapitab.c/.h`: the Java Card API's package, class and method tokens, generated by
  `tools/gen_jcapi.py` from the export files of Oracle's Java Card Development Kit (not included).
- The EV1 counter tear-off (`nfcprobe/source/mfutear.c`, `tools/exp/tear/countertear.py`) follows
  Quarkslab's "RFID Monotonic Counter Anti-Tearing Defeated".
- `javacard/build.xml` builds Yubico's ykneo-oath (GPL-3.0) from a separate clone; it is not included.
